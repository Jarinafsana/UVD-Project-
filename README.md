# UVD-Project-
Our project adopts traffic stop data in the US with data available to show insights into age, race and outcomes. The project brief has been refined with an audience now intended for state police officials, making future training more targeted based on past data


Project Motivation:
Police stop data holds historical patterns that could improve how current officers are trained
State data shows a broader picture which hasn't been shared on a county level
Help state police officials target future training using evidence from past stops


Project Audience:
State police officials, their training and policy decision makers but not the general public or data specialists


Project Function:
Explanatory not explore nor exhibit
Guide officials to clear, evidence based findings about stop patterns
Point to specific traffic stop priorities
